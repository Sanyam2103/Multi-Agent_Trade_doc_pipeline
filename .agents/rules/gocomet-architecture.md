# GoComet Multi-Agent Architecture Rules
* All backend code must be written in Python using FastAPI.
* Use strict Pydantic typing for all data models and state management.
* The multi-agent orchestration must be handled using LangGraph.
* Do not write monolithic functions. Keep routing logic separate from extraction logic.
* Do not remove any Pyrefly comments in any file.
* Use PEP 8 styling and document all methods.
